# Málaga-helg – reseplanerare

Statisk webbplats för en resa till Málaga 6–8 november 2026.

- **Resplan**: dag för dag (fredag från Av. de Velázquez 212, sedan Calle Comedias 18; dagsutflykt på lördag; söndag förmiddag) med matställen för runt 25 € per person.
- **Utmaningar**: 60 Málagautmaningar med poäng för två spelare. Poängen sparas i en cookie (med localStorage som backup).

Öppna `index.html` i en webbläsare eller aktivera GitHub Pages på grenen `main`.
